# app/api

## Overview
Next.js application API router blueprint organizing authentication, agent proxying, webhooks, and Dark Factory operations.

## Subdirectories & Boundaries
- [architecture](./architecture/README.md) - Documentation endpoint serving ARCHITECTURE.md
- [auth](./auth/README.md) - Google OAuth, developer sign-in, and session routes
- [dark-factory](./dark-factory/README.md) - Dark Factory operations API
- [eve](./eve/README.md) - Reverse proxy to Eve agent runtime
- [github](./github/README.md) - Inbound GitHub webhook endpoints
- [releasenotes](./releasenotes/README.md) - Release notes endpoint
